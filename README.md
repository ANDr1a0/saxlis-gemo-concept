# Saxlis Gemo | Unofficial website concept

**Not commissioned, approved or owned by the restaurant.** This is an independent design demonstration for a possible client proposal.

## Features
- Georgian and English (KA/EN)
- Responsive desktop and mobile layout, accessible links
- Example Georgian dishes (NOT an official verified menu)
- Public address, telephone and links to the restaurant's social pages
- Editorial image gallery using Creative Commons photography
- Robots noindex / nofollow to avoid misleading search indexing

## Photo use
Original restaurant photographs were discovered on public social profiles, but they have NOT been rehosted or copied into this public demo without permission. The site links to the restaurant's own Instagram/Facebook. All displayed photos are illustrative and clearly labeled.
